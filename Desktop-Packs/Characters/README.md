# 角色包

把完整角色目录放在这里，例如 `Desktop-Packs/Characters/my-character/`。
在设置中点击 **导入角色文件夹**，选择直接包含 `meta.json` 的目录，导入完成后重启程序。

可直接导入的轻量示例：[静态角色](Examples/static/)和[眼部动态角色](Examples/eye-rig/)。
示例不包含语音模型；制作角色卡、模型配置和个人存档的方法见[角色包教程](../../docs/CHARACTER_PACKS.md)。

完整角色包默认不进入 Git；示例与本说明随源码提供。
本目录存放源包，已安装副本由 `data/runtime/characters/` 管理，私人状态由 `data/runtime/character_states/` 管理。
