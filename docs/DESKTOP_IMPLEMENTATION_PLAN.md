## 已确认范围

- 保留聊天、角色包、语音、记忆、立绘、桌宠、屏幕理解、陪玩、看番和唱歌。
- 保留可选 Home：感知亮屏、闹钟/叫醒/结束语、晚安、灯控、欢迎/告别、
  支持的平台休眠与定时恢复、设备校准。未配置硬件不阻止普通桌面使用。
- 本机通知保留；不接入 QQ 投递、远程 Codex、跨端待处理和离席召回。
- 不引入手机、机器人、QQ、Hub/Presence 跨端运行链及远端部署。
- 复用当前 AppHost、ChatEngine/run_turn、port/adapter、RuntimeEvent 边界。
  不整份替换成四端主仓，不复制私有密钥、记忆、地址和设备校准数据。
- `main` 最终是跨平台产品；Linux/Windows 分支用于平台集成验证，共用功能归入 main。
  施工阶段先保留在任务工作树；用户随后明确授权提交、合并 main 并 push，部署另行安排。
