# Windows 验收记录 · 2026-10-09

基线为公开仓库 `main` 的 `326fcb92e52799a60632c0e27068bcd37f5a7976`，施工分支为 `codex/windows-native-20261009`。本轮保留独立桌宠范围，没有引入共享核心、Hub、QQ、手机或机器人业务服务。

## 环境与修改

只使用现有 Windows Python 3.11.17 环境。核心版本：PyTorch 2.6.0+cu124、Transformers 4.57.6、NumPy 1.26.4、Qwen-ASR 0.0.6、Silero VAD 6.0.0、ONNX Runtime GPU 1.26.0；GPU 为 RTX 4090。仅追加 Cubism 声明的可选依赖 live2d-py 0.7.0.4 / PyOpenGL 3.1.10，没有升级或替换原有包。

主要修复：

- Windows 原生配置事务：文件锁、私有 ACL、文件身份、原始字节恢复及目录联接拒绝。
- API Key 保存从创建临时文件起即使用私有 Windows ACL，避免继承项目目录的其他用户读取权限；Linux 保留 0600。
- 换装配置的原子保存不再调用 Windows 缺少的 `fchmod` / POSIX 目录 fsync。
- 游戏记忆 SQLite 连接在操作结束后及时关闭。
- TTS/RVC 打包正确处理 Windows 分隔符及路径大小写；跳过目录联接。
- 启动器将 UTF-8 传给 Python 子进程，配置脚本报告实际使用的解释器。
- 首次文字配置真正导入静态示例；已有仓库模板可通过显式 `--configure-text` 配置。
- Windows Qwen 与 TTS/RVC 使用同一环境；Linux 保留独立 Qwen 环境和原主环境依赖标记。
- Qwen 先初始化数学库再读取父进程管道，修复 Windows 预热死锁。
- `megumin_d` 的 TTS 入口按需加载 v3 超分模块，使 v2ProPlus 能在现有精简包中运行。
- 窗口按钮补充与工具提示一致的可访问名称。
